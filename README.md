### How to Run

To process images and detect lanes, run the `main.py` script with the following command:

```bash
python main.py --input_folder <path_to_your_input_images> --output_folder <path_to_your_output_directory>
```

**Example:**

```bash
python main.py --input_folder ./images --output_folder ./results
```
